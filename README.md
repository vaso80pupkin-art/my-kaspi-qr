# Личный Kaspi QR

Статическая мобильная страница-визитка для быстрого перевода через Kaspi.kz. HTML, CSS, JavaScript и генератор QR-кода находятся локально в `docs/`; сервер, база данных и удалённые runtime-зависимости не требуются.

## Персональные данные

Перед публикацией откройте `docs/index.html` и в начале встроенного скрипта замените поля `RECIPIENT.name`, `RECIPIENT.phone` и `RECIPIENT.avatarUrl`. Сейчас указаны демонстрационные значения: `Александр К.` и шаблон `+7 (7XX) XXX-XX-XX`. Не публикуйте страницу, пока не проверите номер и фото.

## Kaspi и QR-код

На странице можно ввести сумму перевода в тенге и назначение платежа. Кнопка рядом с каждым полем копирует его отдельно; затем вставьте значение в Kaspi вручную. Главная кнопка по-прежнему копирует номер телефона и открывает Kaspi: на Android — через Intent для `kz.kkb.client`, на других устройствах — через ссылку `https://kaspi.kz`. Сумма и назначение не передаются в приложение автоматически.

Блок внизу страницы создаёт QR-код текущего адреса локально в браузере и скачивает его как PNG. После публикации сгенерируйте QR-код уже по постоянной ссылке сайта.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, каталог `/docs`. Файлы сайта уже лежат в нужном каталоге. Для аккаунтов/планов, где GitHub Pages недоступен для приватного репозитория, сначала требуется разрешить публичную видимость репозитория или выбрать поддерживаемый план.

## Локальный просмотр

Откройте `docs/index.html` в браузере или раздайте каталог `docs` любым простым статическим сервером. Для проверки копирования и deep links удобнее использовать HTTPS или локальный сервер.

## Лицензия QR-библиотеки

`docs/qrcode.min.js` — библиотека `qrcode-generator` версии 1.4.4, распространяемая по MIT License. Она включена локально, поэтому генерация QR-кода не зависит от внешнего CDN.
